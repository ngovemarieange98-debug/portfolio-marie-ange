Application de gestion des notes scolaires

Une application destinée à organiser les utilisateurs, les matières, les notes et les informations scolaires dans une interface centralisée.

Présentation du projet

Cette application vise à faciliter la gestion des notes et des données académiques. Les captures ci-dessous présentent l’interface de connexion, le tableau de bord, la structure de la base de données et le modèle conceptuel de données (MCD).

Fonctionnalités présentées

  • Interface de connexion et création de compte selon le rôle de l’utilisateur.
  • Tableau de bord avec accès aux principales rubriques de gestion académique.
  • Base de données relationnelle pour organiser les utilisateurs, étudiants, matières, semestres et notes.
  • MCD permettant de visualiser les entités et les relations principales.

Démarche de conception

  1. Identifier les besoins des utilisateurs et les rôles nécessaires.
  2. Concevoir le MCD et structurer les tables de la base de données.
  3. Développer les écrans de connexion et le tableau de bord.
  4. Tester les opérations de gestion et la cohérence des données.
Confidentialité

Les informations personnelles et les empreintes de mots de passe visibles dans certaines captures ont été masquées pour éviter leur publication.
