# Application de gestion des notes scolaires

## Présentation
Application de gestion des données académiques avec interface de connexion, tableau de bord et base de données relationnelle.

## Galerie incluse
- `images/connexion.jpg` : interface d’inscription / connexion (adresse e-mail masquée).
- `images/tableau-de-bord.jpg` : tableau de bord de l’application.
- `images/base-de-donnees.jpg` : vue de la base de données (adresses e-mail et hashes de mots de passe masqués).
- `images/mcd.jpg` : modèle conceptuel de données.

La fiche `index.html` affiche les quatre captures avec des légendes et permet de les agrandir en cliquant dessus.

Avant publication, vérifiez que les captures ne révèlent aucune autre donnée personnelle ou information confidentielle.
