# Simulation d'un réseau avec VLAN dans Cisco Packet Tracer

**État :** projet prévu — à mettre à jour une fois la simulation réalisée.

## Objectif
Créer un réseau segmenté en VLAN afin de séparer les groupes d'utilisateurs et de documenter les communications autorisées.

## Étapes suggérées
1. Définir le plan d'adressage et les VLAN nécessaires.
2. Créer les VLAN sur les commutateurs et affecter les ports d'accès.
3. Configurer les liens trunk.
4. Configurer le routage inter-VLAN si le scénario le demande.
5. Tester la connectivité avec des pings et documenter les résultats.

## Livrables à ajouter
- Fichier Cisco Packet Tracer `.pkt`.
- Schéma et tableau d'adressage.
- Extraits de configuration non sensibles et captures des tests.
- Rapport PDF décrivant les choix et les résultats.
